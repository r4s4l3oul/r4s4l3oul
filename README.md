Laboratoire Active Directory personnel déployé dans un environnement virtualisé afin de travailler l'administration Windows Server, la gestion d'un domaine et l'audit de sécurité Active Directory.

**Dépôt :** https://github.com/r4s4l3oul/ActiveDirectory_lab

**Infrastructure mise en place :**

- Contrôleur de domaine Windows Server
- Postes clients Windows joints au domaine
- Utilisateurs, groupes de sécurité et unités d'organisation
- Stratégies de groupe GPO
- DNS Active Directory
- Partages SMB
- Permissions NTFS et contrôle d'accès par groupe

**Axes sécurité travaillés :**

- Énumération Active Directory
- Analyse LDAP, SMB et Kerberos
- Collecte et analyse BloodHound
- Identification de chemins d'attaque
- Analyse des privilèges et délégations
- Recherche de mauvaises configurations
- Compréhension des risques d'escalade de privilèges en environnement Windows
